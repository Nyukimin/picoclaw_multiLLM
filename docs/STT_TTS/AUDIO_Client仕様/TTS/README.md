# TTS 正本ドキュメント

本ディレクトリ直下は、正本として次の3ファイルのみを配置する。

1. `README.md`（本書）
2. `実装仕様.md`（契約仕様）
3. `実装.md`（実装・運用・TDD実行手順）

## 目的
- Chat 連携で利用する TTS（SBV2 含む）の契約と実装方針を一本化する。
- 旧資料の重複・差分を解消し、参照先を明確化する。

## 正本の使い分け
- `実装仕様.md`
  - API/WS 契約、エラー契約、受け入れ基準の正本。
  - Provider 非依存の基本契約と、現行 SBV2 実装準拠の要点を併記。
- `実装.md`
  - 実装時の設定、TDD 手順、テストID運用、実行順序の正本。

## 参照ルール
- 仕様判断が必要な場合は、まず `実装仕様.md` を優先する。
- 実装作業・テスト実行時は `実装.md` を優先する。
- 文言不一致がある場合、直近更新日の正本を採用し、必要に応じて同時更新する。
