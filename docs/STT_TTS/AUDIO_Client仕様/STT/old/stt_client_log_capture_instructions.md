# クライアントログ採取指示書（貼り付け用）

## 目的
サーバーログと比較できるように、クライアント側の STT イベントを時系列で記録する。

## 記録形式（必須）
- 1行目: `HH:MM:SS · event_type`
- 2行目: ペイロード（なければ `-`）

例:
```text
10:58:22 · final
です。
10:58:21 · draft
どうも、どうもありがとうございました。
10:58:18 · speech_start
-
```

## 採取手順
1. クライアント画面を開く（対象URLを明記）。
2. マイク許可を実施。
3. 10〜20秒程度の連続発話を実施。
4. 画面のイベントログ（`speech_start` / `draft` / `final`）を上記形式でコピー。
5. ファイル名 `tmp/client_stt_log.txt` で保存。

## 併記してほしい情報
- クライアント接続先 URL（HTTP/HTTPS）
- WS URL（例: `ws://127.0.0.1:8090/ws`）
- 試験時刻（開始〜終了）
- 発話したテキスト（おおよそで可）

## NG例
- 時刻がない
- event_type がない
- `final` の本文が抜けている
