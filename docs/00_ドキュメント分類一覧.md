## 分類ルール

- `coding`: 実装時に直接参照する仕様
- `ops`: 運用時に参照する手順
- `prompt`: プロンプト資産として使う設計

## 使い分けガイド

- 実装で迷ったら `01_正本仕様/実装仕様.md` を最優先で参照する。
- IdleChat で迷ったら `01_正本仕様/03_IdleChat.md` を入口にし、詳細は `09_IdleChat仕様/` を参照する。
- LLM 入出力や prompt を触る場合は `05_LLM運用プロンプト設計/` を併読する。
- 運用フロー確認は `06_実装ガイド進行管理/` を参照する。
- 旧資料は直接更新せず、必要な内容を正本または該当カテゴリへ移す。
