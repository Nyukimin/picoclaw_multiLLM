# 旧仕様未実装候補

## 目的

この文書は、`docs/10_新仕様/` 以外の仕様文書に残っている未実装、部分実装、保留、旧仕様候補をまとめた棚卸しである。

`docs/10_新仕様/` を現行仕様入口とする前提で、旧 docs 側の記述が次のどれに当たるかを判定する。

- `docs/10_新仕様/` に反映すべき現行仕様
- すでに `docs/10_新仕様/` に反映済みの項目
- 旧仕様または OpenClaw 移植差分として分離すべき項目
- 判断保留として残す項目

この文書は調査サマリであり、実装仕様の一次参照は各 `docs/10_新仕様/*.md` と `13_実装項目インベントリ.md` とする。

## 運用メモ

- 旧 docs の「未実装」表記は現行コードとずれているものがある。
- 現行実装として必要なものは `13_実装項目インベントリ.md` に反映する。
- OpenClaw 移植差分は、RenCrow 本線に入れる前に `旧仕様・移行対象外` または `判断保留` として分ける。
- archive 文書は履歴参照専用であり、仕様判断の一次参照にしない。
